05

IDE-parity shell — tabs, pins, fullscreen terminal

New · 0.9.0

The mutually-exclusive Dashboard / LogPanel / StackDetail switcher is gone. Every project lives in its own tab in a Cursor-style strip pinned above the content area, and tabs stay mounted via display: none so terminal sessions, log filters, split-pane heights, scroll positions and AI conversation drafts survive every switch. Pinning + drag-to-reorder (axis-locked, zone-aware) + a VSCode-parity right-click menu (Pin · Move Left / Right · Close · Close Others / Right / Left / All) round out the IDE feel — and bulk-close gestures never touch what you've pinned. The LogPanel toolbar grew an Expand button so the embedded terminal can fill the entire content area when you need it (Esc restores), and the dashboard finally has a /-to-focus search box that ranks across name, tags, port, command, and cwd.

06

AI Commit Generator

New · 0.9.0

The Sparkles button on the Commit panel writes the message directly into your textarea instead of bouncing through the chat hub. One provider configured → instant generation; two-or-more → a small model-chooser popover anchored under the button. Whatever you've already typed forwards as a hint, so "scope: api" or "make it imperative" steers the regenerate. The new prompt contract wraps the answer in <commit>…</commit> sentinel tags so reasoning-heavy models (DeepSeek-R1, GLM-4.x, Qwen-QwQ, OpenAI o-series) stop dumping their "1. Analyze the request… 2. Determine the prefix…" monologue into your textarea — we extract only what's between the tags, with a <think>-stripping fallback for older models. Plus a per-provider Commit Message language override, independent from Response language, so chat in Türkçe + commits in English finally has a home.

Sparkles click 1 provider → instant fill
Sparkles click 2+ providers → chooser popover
<commit> tags R1 / GLM / QwQ no leaked reasoning
Commit lang TR · EN chat ≠ commit

Install

Get it running.

Recommended

Download a release

Prebuilt binaries for macOS, Linux and Windows are published on every tagged release. No toolchain required — download, install, run.

  • macOS .dmg Apple Silicon + Intel
  • Linux .AppImage · .deb x86_64
  • Windows .msi · .exe x86_64
Download latest release
Releases are built automatically on every tag push via GitHub Actions — always in sync with main.

macOS first launch: if you see "RunHQ is damaged", run xattr -cr /Applications/RunHQ.app once. RunHQ isn't Apple-notarized yet (coming soon); Homebrew installs skip this step automatically.
For hackers

Build from source

Clone the repo, install deps, run in dev mode with hot reload, or bundle your own signed release with pnpm tauri:build.

Step 01 · Prereqs
Node 20+ · pnpm 9+ · Rust ≥ 1.77 · Tauri deps
Step 02 · Clone & install
$ git clone github.com/erdembas/runhq
cd runhq && pnpm install copy
Step 03 · Run in dev
$ pnpm tauri:dev copy
Hot reload, full devtools and the same build we ship — bundle a release with pnpm tauri:build.
Package managers

One-line install for your OS.

macOS Homebrew
$ brew tap erdembas/tap
brew install --cask runhq copy
Upgrade: brew upgrade --cask runhq
Windows winget
> winget install erdembas.RunHQ copy
Upgrade: winget upgrade erdembas.RunHQ
Linux .deb · AppImage
$ gh release download --repo erdembas/runhq --pattern "*.deb"
sudo dpkg -i RunHQ_*_amd64.deb copy
Prefer a browser? — download the .deb or AppImage from releases.
